# Общие требования к написанию постов

- Начинай публикацию с сильного hook, который вызывает интерес к дальнейшему чтению.
- Не используй кликбейт и хайп.
- Делай короткие абзацы и оставляй визуальный воздух между смысловыми блоками.
- Одна публикация должна раскрывать одну основную идею.
- Не увеличивай текст искусственно ради рекомендуемого количества символов.
- Используй эмодзи умеренно и функционально: для навигации, смысловых акцентов и структуры.
- Не ставь эмодзи автоматически перед каждым абзацем или пунктом.
- Не добавляй CTA ради CTA. Призыв должен логично следовать из содержания публикации.
- Не добавляй хэштеги автоматически.
- Избегай длинных вступлений перед основной мыслью.
- Сохраняй авторский стиль и позиционирование при адаптации текста.

# Telegram

**Длина:** 800–1000 символов. Полноценный пост без кнопки «читать далее».

**Хэштеги:** не используй.

**Структура:**
1. Заголовок (хук) — должен сразу обозначить проблему, интригу, наблюдение или пользу.
2. Абзацы: короткие, примерно 1–3 предложения. Между смысловыми блоками — пустая строка.
3. Структура: Hook → раскрытие мысли → примеры/аргументы → вывод → CTA.
4. CTA: обязателен для каждого поста - определи по тексту поста наиболее подходящий CTA (подписаться на канал, оставить комментарий, задать вопрос в комментариях, сохранить).

# Instagram

Основной формат контента для Instagram — пост-карусель.

Контент для Instagram необходимо создавать сразу как сценарий карусели.
Не создавай сначала длинный пост с последующим механическим разделением текста на слайды.

Каждый слайд должен представлять собой отдельный законченный смысловой блок.

**Количество слайдов:** Рекомендуемое количество: 6–10 слайдов. 
Количество слайдов определяется содержанием материала.
Не растягивай короткую мысль искусственно ради увеличения количества слайдов и не объединяй несколько сложных смыслов на одном слайде ради уменьшения их количества.

**Структура карусели:**
1. Слайд 1 — обложка / hook — Задача — остановить внимание и вызвать желание листать карусель дальше.
Используй:
- сильное утверждение;
- вопрос;
- проблему;
- неожиданный факт;
- обещание конкретной пользы;
- интригу.

Не используй кликбейт.

2. Слайд 2 — контекст / проблема. 
Кратко объясни, почему тема важна и зачем человеку читать дальше.

3. Основные слайды — Раскрой идею последовательно.
Один слайд = одна основная мысль.
Это могут быть:
- шаг;
- правило;
- тезис;
- ошибка;
- пример;
- объяснение;
- рекомендация.

Каждый следующий слайд должен логически продолжать предыдущий.

4. Предпоследний смысловой слайд — вывод.
Сформулируй главную мысль карусели или практический результат.

5. Последний слайд — CTA

Добавляй CTA только тогда, когда существует естественное следующее действие.

Например: сохранить карусель, попробовать промпт, применить инструкцию, поделиться материалом или перейти к дополнительному материалу.

Не используй искусственные CTA исключительно ради вовлечения.

**Instagram caption**

Помимо карусели создай подпись к публикации.

Caption не должен полностью пересказывать содержание слайдов.

6. Сохрани контент для Instagram отдельно в формате `.json` в папку:

   `output/posts/instagram/`

7. Instagram-контент должен быть сохранён как валидный JSON и содержать только структуру карусели:
   - `schema_version`
   - `post`
   - `format`
   - `slides`
   - `caption`
   - `cta`

8. Пример итогового JSON для instagram
```json

{
  "schema_version": "instagram-carousel/v1",
  "post": "Безопасность при использовании ИИ",
  "format": "carousel",
  "slides": [
    {
      "slide": 1,
      "role": "hook",
      "headline": "Стоп: ты отправляешь это в ИИ?",
      "body": ""
    },
    {
      "slide": 2,
      "role": "context",
      "headline": "Мы делимся слишком многим",
      "body": "Документы, переписки, таблицы и даже личные данные всё чаще попадают в нейросети — иногда без лишних раздумий."
    },
    {
      "slide": 3,
      "role": "content",
      "headline": "Правило цифровой безопасности",
      "body": "Не отправляй пароли, банковские данные, паспорта и конфиденциальные файлы. Если нужно — сначала обезличь информацию."
    }
  ],
  "caption": "Мы всё чаще используем ИИ как личного помощника — и так же часто забываем о безопасности данных. Простой чек перед отправкой может защитить тебя от больших проблем.",
  "cta": "Сохрани, чтобы не забыть"
}
```

# ВКонтакте

**Длина:** 1 000–2 500 символов. ВКонтакте обрезает текст кнопкой «Показать полностью» после ~300 символов — первые два предложения должны цеплять, остальное раскрывает суть.

**Хэштеги:** не используй.

**Структура:**
1. Крючок — первые 1-2 предложения до обрезки. Конкретный факт или провокационный вопрос, без воды.
2. Структура поста: hook → раскрытие темы → основная польза / примеры → вывод → CTA при необходимости
Структура может меняться в зависимости от типа публикации.
3. CTA — вопрос к аудитории или призыв сохранить/поделиться. Вопросы дают комментарии, которые поднимают пост в алгоритме.

**Тон:** ближе к Telegram, чем к Instagram. Можно быть чуть более разговорным — ВК привычен к живому стилю без глянца.

**Пример:**

```text
ИИ напишет посты для твоих соцсетей за 5 минут🔥

Специально для тех, кому некогда вести соцсети, я создала умный шаблон, который за считанные минуты генерирует готовый контент под твою нишу.

✅Что вы получите:

👉Экономию времени: контент на 2 недели готов, пока ты допиваешь кофе.

👉Точное попадание: ИИ пропишет цепляющие заголовки, креативные тексты и даст рекомендации по оформлению постов.

👉Свободу: ты наконец-то делегируешь рутину технологиям и займешься своим делом.

❤️‍🔥Пиши СОЦСЕТИ в комментариях, и я пришлю тебе ссылку на шаблон
```
