# Brand Style

Файл описывает фирменный стиль Instagram-каруселей Виолетты.

Используй его как источник истины для `carousel-renderer`.
Content Maker не должен добавлять визуальный стиль в текстовый JSON.

---

# Общая идея

Стиль карусели — темный минимализм с крупной выразительной типографикой и большим количеством свободного пространства.

Слайды должны выглядеть спокойно, уверенно и взросло: без перегруженных декоративных элементов, без пестроты, без лишних иконок и без визуального шума.

Главный акцент — текст.

---

# Формат

Основной формат:

```text
1080x1350 px
```

Это вертикальный Instagram carousel portrait format.

Безопасные поля:

```text
top: 70 px
right: 70 px
bottom: 70 px
left: 70 px
```

Основной текстовый блок должен располагаться ближе к нижней половине слайда:

```text
content_top: 500-560 px
content_left: 70 px
content_right: 70 px
```

Если текста больше, можно поднимать блок выше, но нельзя заполнять весь слайд. Воздух сверху должен сохраняться.

# Типографика

## Headline

Шрифт:

```text
El Messiri
```

Начальный размер для обычных смысловых слайдов:

```text
64 px
```

Размер для коротких сильных заголовков:

```text
72 px
```

Размер для длинных заголовков:

```text
56 px
```

Вес:

```text
700
```

Line height:

```text
1.08
```

Letter spacing:

```text
0
```

Правила:

* headline должен занимать 1-3 строки;
* не сжимай межбуквенное расстояние;
* если заголовок не помещается, уменьши размер до 56 px;
* если всё ещё не помещается, добавь предупреждение в manifest, чтобы пользователь мог сократить headline.

## Body

Шрифт:

```text
Montserrat
```

Начальный размер:

```text
36 px
```

Размер для длинного body:

```text
32 px
```

Минимальный размер:

```text
30 px
```

Вес:

```text
400
```

Line height:

```text
1.45
```

Letter spacing:

```text
0
```

Правила:

* body должен быть легче headline и визуально спокойнее;
* body может занимать 2-5 строк;
* если текста больше, лучше разбить слайд или сократить текст;
* не уменьшай body ниже 30 px без явного решения пользователя.

## Account Label

В верхнем левом углу используется связка:

```text
avatar + @vita_vlasova
```

Аватар должен располагаться слева от названия аккаунта.

Источник аватара:

```text
assets/avatar.png
```

Размер аватара:

```text
46x46 px
```

Положение аватара:

```text
top: 48 px
left: 70 px
```

Расстояние между аватаром и названием аккаунта:

```text
gap: 12 px
```

Если файл аватара отсутствует, не останавливай весь рендер, но добавь предупреждение в `manifest.json`.

Текст:

```text
@vita_vlasova
```

Шрифт:

```text
Montserrat
```

Размер:

```text
24 px
```

Вес:

```text
400
```

Цвет:

```text
#ffffff
opacity: 70%
```

Положение:

```text
top: 58 px
left: 128 px
```

# Композиция

Слайд строится на трех зонах:

1. Верхняя служебная зона.
2. Большая пустая зона.
3. Текстовый блок ближе к нижней половине.

Текстовый блок:

```text
max_width: 860-940 px
gap_between_headline_and_body: 64 px
```

Headline располагается над body.
Body начинается ниже headline с заметным, но не чрезмерным отступом.

Слайд не должен выглядеть как презентационная карточка с рамками.
Не используй карточки, плашки, бордеры, яркие контейнеры и декоративные блоки по умолчанию.

---

# Навигационные элементы

## Account label

На каждом рендеримом слайде в левом верхнем углу должна быть связка аватара и подписи:

```text
assets/avatar.png
@vita_vlasova
```

Аватар располагается слева, подпись справа от аватара.
Подпись полупрозрачная, белая, спокойная.

## Slide counter

Нумерация слайдов в правом верхнем углу не нужна.

Не добавляй:

```text
1/8
2/8
7/8
```

## Next arrow

На всех слайдах, кроме последнего, в правом нижнем углу должна быть только стрелка вправо.

Текст `листай дальше` не добавляй.

Стрелка:

```text
type: custom line arrow
color: #ffffff
length: 135 px
stroke_width: 4 px
opacity: 100%
bottom: 70 px
right: 70 px
```

Стрелка должна быть крупной, хорошо заметной и примерно в три раза длиннее обычного символа `→`.
Рисуй ее как линию с наконечником, а не как текстовый символ, чтобы результат не зависел от поддержки глифа в шрифте.

На последнем слайде стрелки быть не должно.

# Первый слайд

`carousel-renderer` не создает первый слайд карусели.

Первый слайд считается обложкой, которую пользователь берет из изображения, созданного `image-generator`.

Правило:

* если во входном Instagram JSON есть `slide: 1` с ролью `hook`, не рендери его в PNG;
* начинай экспорт с `slide: 2`;
* сохрани связь с исходными номерами слайдов в `manifest.json`;
* имена экспортированных файлов должны отражать исходный номер слайда, например `slide-02.png`, `slide-03.png`;
* не перенумеровывай слайды внутри текста без явного запроса пользователя.

# Layout Rules

## Context, Content, Conclusion

Используй общий текстовый layout:

```text
account label сверху слева
большой пустой верх
headline в нижней половине
body под headline
стрелка справа снизу, если это не последний рендеримый слайд
```

## CTA

CTA-слайд может быть чуть более центрированным по вертикали, но должен сохранять много воздуха.

Если CTA является последним слайдом, не добавляй стрелку.

---

# Чего избегать

Не используй:

* slide counter;
* текст `листай дальше`;
* плашки и карточки по умолчанию;
* дополнительные декоративные иконки без необходимости;
* градиентные фоны;
* сложные иллюстрации внутри текстовых слайдов;
* мелкий текст;
* плотную верстку без воздуха;
* автоматическое добавление эмодзи;
* негативный letter spacing.

---

# Итоговые правила

Используй как постоянные правила бренда:

* темный однотонный фон;
* аватар и аккаунт `@vita_vlasova` слева сверху;
* много пустого пространства;
* крупный headline в нижней половине;
* body ниже headline;
* спокойную типографическую композицию;
* без счетчика справа сверху;
* без текста `Листай дальше`;
* только крупная длинная белая стрелка справа снизу на всех слайдах, кроме последнего;
* первый слайд не рендерить, потому что обложка берется из `image-generator`.
